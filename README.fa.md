# هم‌سو &nbsp;·&nbsp; Hamsoo

**تایپوگرافی فارسی و راست‌چین برای رابط‌های گفتگوی هوش مصنوعی.**

دستیارهای هوش مصنوعی فارسی را خوب می‌نویسند، اما بد نمایش می‌دهند؛ چپ‌چین، فشرده،
و با نشانه‌های نگارشی که به انتهای اشتباه خط پرتاب می‌شوند. هم‌سو این تایپوگرافی را
درست در همان صفحه و درون مرورگر شما اصلاح می‌کند، بدون دست زدن به متن.

## چه کار می‌کند

رابط‌های گفتگو برای متن چپ‌به‌راست ساخته شده‌اند. وقتی پاسخ فارسی است، صفحه همان
فرض‌های لاتین را نگه می‌دارد و نتیجه به شکل‌هایی غلط می‌شود که خواندنش خسته‌کننده است:

| مشکل | کاری که هم‌سو می‌کند |
| :--- | :--- |
| پاراگراف فارسی چپ‌چین در ستون چپ‌به‌راست | جهت پایه را برای هر عنصر تشخیص می‌دهد و می‌چرخاند |
| پرتاب شدن نقطه یا دونقطهٔ پایان جمله به سمت اشتباه | حل درست دوجهتی بودن متن، تا نشانه‌ها سر جای خود بنشینند |
| آینه‌شدن غلط نشانهٔ فهرست‌ها و ستون جدول‌ها | فهرست و جدول به صورت یکپارچه می‌چرخند، نه مورد به مورد |
| چرخیدن بلوک‌های کد همراه متن | کد، کد درون‌خطی و پیوندها چپ‌به‌راست می‌مانند |
| فونت‌های پیش‌فرض لاتین و نمایش بد فارسی | شش فونت فارسی همراه، یا هر فونتی که خودتان بدهید |
| فاصلهٔ سطری فشردهٔ مناسب حروف لاتین | کنترل مستقل اندازه، ارتفاع سطر، ضخامت، فاصله و عرض |
| ارقام لاتین درون جملهٔ فارسی | تبدیل اختیاری به `۱۲۳` یا `١٢٣` |
| تغییر جهت تایپ در کادر نوشتن | اعمال جهت روی کادر ورودی، از همان نخستین حرف |

جهت متن بر اساس **نخستین حرف قوی** تعیین می‌شود — همان رفتار `dir="auto"` — و نسبت حروف
فقط به عنوان پشتیبان به کار می‌رود. این جزئیات مهم است: جملهٔ فارسی‌ای که یک عبارت بلند
انگلیسی را نقل می‌کند هنوز جمله‌ای فارسی است، و روش‌های مبتنی بر شمارش حروف در همین جا
اشتباه می‌کنند.

## امکانات

### تایپوگرافی

| امکان | جزئیات |
| :--- | :--- |
| فونت‌های فارسی همراه | وزیرمتن، استعداد، ساحل، شبنم، صمیم، گندم |

| کنترل‌های خوانایی | اندازه، ارتفاع سطر، ضخامت، فاصلهٔ حروف، چینش و عرض ستون |
| تنظیم جداگانه برای هر سایت | تایپوگرافی متفاوت برای هر دامنه، جداگانه ذخیره می‌شود |

### جهت و متن

| امکان | جزئیات |
| :--- | :--- |
| تشخیص خودکار راست‌چین | برای هر عنصر، و بازبینی در حین رسیدن پاسخ جریانی |
| مدیریت محتوای ترکیبی | عبارت‌های لاتین درون فارسی جهت خود را حفظ می‌کنند و برعکس نمی‌شوند |
| ایمن برای کد | `pre`، `code`، پیوندها و کادرهای ورودی هرگز نمی‌چرخند |

| جهت کادر نوشتن | کادرهای ورودی از همان حرف اول درست رفتار می‌کنند |
| پاکسازی متن چسبانده‌شده | نویسه‌های کنترلی نامرئی دوجهتی حذف می‌شوند |
| پشتیبانی Shadow DOM | ریشه‌های shadow باز هم استایل می‌گیرند؛ چیزی که بیشتر افزونه‌ها از قلم می‌اندازند |

| همگام‌سازی میان دستگاه‌ها | تنظیمات همراه پروفایل مرورگر می‌آیند |

| راهنما و گزارش اشکال | نخست راه‌حلهای خودتان برای سایتی که درست نمایش داده نمی‌شود، سپس گزارش از پیش پر‌شده با issue یا ایمیل |

## نصب

### فایرفاکس — از فروشگاه افزونه‌ها (پیشنهادی)

**[افزودن به فایرفاکس](https://addons.mozilla.org/en-US/firefox/addon/hamsoo-%D9%87%D9%85-%D8%B3%D9%88/)** —
نصب با یک کلیک و به‌روزرسانی خودکار. نیازمند فایرفاکس ۱۴۰ یا بالاتر.

### مرورگرهای کرومیوم — Chrome، Edge، Brave، Opera

1. مخزن را کلون کنید و خروجی را بسازید:

   ```bash
   git clone https://github.com/NaxonM/hamsoo.git
   cd hamsoo/hamsoo-addon
   npm run build
   ```

2. به نشانی `chrome://extensions` (یا `edge://extensions`) بروید.
3. گزینهٔ **Developer mode** را روشن کنید.
4. روی **Load unpacked** کلیک کنید و پوشهٔ `dist/hamsoo-chromium` را انتخاب کنید.

### فایرفاکس — نصب موقت از سورس

1. پس از اجرای `npm run build`، به نشانی `about:debugging#/runtime/this-firefox` بروید.
2. روی **Load Temporary Add-on…** کلیک کنید.
3. فایل `dist/hamsoo-firefox/manifest.json` را انتخاب کنید.

### از بستهٔ آماده

بستهٔ `hamsoo-chromium.zip` یا `hamsoo-firefox.zip` را از بخش
[Releases](https://github.com/NaxonM/hamsoo/releases) دانلود کنید، از حالت فشرده خارج کنید
و طبق مراحل **Load unpacked** بالا بارگذاری کنید.

## حریم خصوصی و دسترسی‌ها

همه‌چیز به صورت محلی در مرورگر شما اجرا می‌شود. هیچ آنالیتیکس، هیچ تله‌متری، هیچ
سرور راه دور و هیچ درخواست شبکه‌ای. تنظیمات و فونت‌های شما در پروفایل خودتان می‌مانند.

| دسترسی | دلیل نیاز |
| :--- | :--- |
| `storage`، `unlimitedStorage` | ذخیرهٔ محلی تنظیمات و فایل‌های فونت |
| `contextMenus` | انتخابگر عنصر با راست‌کلیک |
| `activeTab`، `scripting` | اعمال استایل روی سایتی که فعال کرده‌اید |
| `*://*/*` (اختیاری) | هنگام نصب **داده نمی‌شود**؛ فقط برای همان سایتی که خودتان اضافه می‌کنید درخواست می‌شود |

گزارش مسائل امنیتی: [`SECURITY.md`](.github/SECURITY.md).

## توسعه

هیچ وابستگی زمان اجرایی و هیچ مرحلهٔ باندلینگی در کار نیست. پوشهٔ `src/` همان چیزی است
که در مرورگر اجرا می‌شود. نیازمند Node ۱۸ یا بالاتر.

```bash
cd hamsoo-addon
npm run check     # لینت و اعتبارسنجی مانیفست و ترجمه‌ها
npm test          # ۲۱۷ آزمون، بدون وابستگی خارجی
npm run build     # خروجی dist/hamsoo-chromium و dist/hamsoo-firefox
npm run verify    # هر سه مورد بالا
npm run preview   # تصویرهای رابط کاربری
npm run version:check  # گزارش همهٔ جاهایی که شمارهٔ نسخه نوشته شده است
npm run release:notes  # متن انتشار و متن فروشگاه، از تاریخچهٔ تغییرات
npm run zip       # بستهٔ قابل انتشار
```

| مسیر | محتوا |
| :--- | :--- |
| `hamsoo-addon/src/` | کد افزونه — اسکریپت محتوا، پس‌زمینه، پنجره، تنظیمات، فونت‌ها |
| `hamsoo-addon/test/` | مجموعهٔ آزمون منتشرشده |
| `hamsoo-addon/build.js` | اسکریپت ساخت (ریشهٔ افزونه، نه `scripts/`) |
| `assets/` | نشان و تصویرهای این مستندات |
| `docs/DEBUGGING-REPORT.md` | دفترچهٔ رگرسیون‌ها؛ کامنت‌های کد به شماره‌های R آن ارجاع می‌دهند |

ابزارهای داخلی دیباگ و ساخت تصویر در پوشهٔ `dev/` قرار دارند که عمداً در مخزن قرار نمی‌گیرد؛
این پوشه از مجموعهٔ آزمون منتشرشده جداست.

## مشارکت

گزارش اشکال و درخواست تغییر هر دو پذیرفته می‌شود. راهنما در
[`CONTRIBUTING.md`](.github/CONTRIBUTING.md) آمده است. پیش از ارسال تغییر، `npm run verify` را اجرا کنید.

اگر سایتی درست نمایش داده نمی‌شود، نشانی آن و یک تصویر را در یک issue بگذارید؛ رابط‌های
گفتگو مدام ساختار DOM خود را عوض می‌کنند و این رایج‌ترین علت خرابی است.
